➕ 如何新增連結 How to add new links

所有連結都嚟自下面呢個 LINKS 陣列（喺 <script> 入面）。想加新連結，淨係要喺陣列度加一行 object，畫面會自動生成卡片、自動歸入分類、自動可以搜尋 — 唔使再手動改 HTML 結構。

{ name: "新連結名稱", url: "https://lofan.github.io/HKJQV/xxx.html", cat: "財經投資" }

如果 cat 打一個未出現過嘅新分類名，個新分類版塊會自動出現喺頁面度，唔使加樣式。想令個分類固定排喺前面，可以喺 CAT_ORDER 陣列度加返個名。

如果將來連結數量多到成百上千，建議轉用 外部 JSON 檔（例如 links.json）再用 fetch() 讀入，或者將呢頁改成配合你嗰個 my-links.html 嘅 localStorage CRUD 工具，咁就可以喺瀏覽器度直接新增/刪除，唔使再手改代碼。
