Claude 官方 13 門線上課程
免費上，仲可以攞官方證書

發佈日期：2026-06-08 ｜ 來源：電腦王阿達 (koc.com.tw)
Anthropic 喺 2026 年 3 月推出 Anthropic Academy，將散落各處嘅學習資料整合成單一平台。13 門課程全部免費、自學制，完成後可獲官方結業證書。由完全唔識 AI 嘅普通用戶，到要搭建 Agent 系統嘅後端工程師，都有對應嘅學習路徑。平台用 Skilljar 管理進度同發證書。

一般用戶路徑（6 門）

無需編程
Claude 101
入門首選。教你用 Claude 處理日常工作：寫信、整理資料、分析文件、草擬內容。涵蓋 Projects、Artifacts、Skills、Connectors、Research Mode 等功能。
→ anthropic.skilljar.com/claude-101
無需編程
Introduction to Claude Cowork
Cowork 係 Claude 直接操作你嘅檔案、資料夾同應用程式嘅功能。涵蓋任務迴圈、Skills 與 Plugins、檔案工作流程，以及延伸到 Chrome、Word 等應用。
→ anthropic.skilljar.com/introduction-to-claude-cowork
無需編程
AI Fluency 系列（4 門）
與愛爾蘭科克大學及美國瑞林藝術設計學院教授合作開發，圍繞「4E 框架」：Effective、Efficient、Ethical、Safe。分別有通用版、學生版、教育者版、教人用 AI 版。
→ anthropic.skilljar.com/ai-fluency-framework-foundations

開發者路徑（7 門）

需要 Python / CLI
Building with the Claude API
開發者必修課。由第一個 API 呼叫到 Agent 系統架構，涵蓋多輪對話、System Prompt、Prompt Engineering、Tool Use、RAG、Extended Thinking、Prompt Caching 及 Agent 平行化架構。
→ anthropic.skilljar.com/claude-with-the-anthropic-api
需要 Python / CLI
Claude Code 101
Anthropic 官方 Agentic 編碼工具入門。涵蓋安裝（終端機、VS Code、JetBrains、Claude Desktop）、核准模式、Plan 模式，以及 Explore → Plan → Code → Commit 工作流程。
→ anthropic.skilljar.com/claude-code-101
需要 Python / CLI
Claude Code in Action
進階實戰。聚焦日常開發工作流整合：上下文管理、自訂指令、MCP Server 整合（連接瀏覽器自動化等外部工具）及 Thinking Mode vs Planning Mode 使用時機。
→ anthropic.skilljar.com/claude-code-in-action
需要 Python / CLI
Introduction to Agent Skills
透過 Markdown 檔案（SKILL.md）擴展 Claude Code 能力。教你撰寫 SKILL.md、設計目錄結構控制上下文視窗消耗，以及企業團隊共享部署。
→ anthropic.skilljar.com/introduction-to-agent-skills
需要 Python / CLI
MCP 系列（2 門）
MCP（Model Context Protocol）係 Anthropic 推出嘅開放標準，讓 AI Agent 透過統一介面連接外部工具。入門課教你用 Python 從零建構 MCP Server 與 Client；進階課深入生產環境部署。
→ 入門課 | 進階課
需要 Python / CLI
雲端平台課程（2 門）
Amazon Bedrock 版：涵蓋 Tool Use、RAG、Agent 架構。Google Vertex AI 版：額外涵蓋 Vision、PDF 處理、Citations。用邊家雲端就讀邊門。
→ AWS Bedrock | GCP Vertex AI

證書制度注意事項

完成課程可攞到 Anthropic 官方結業證書，但呢個同 Claude Certified Architect（CCA） 係兩回事。CCA Foundations 係 2026 年 3 月推出嘅專業認證，針對解決方案架構師，考試難度完全唔同。

簡單講：課程證書 = 「上過課」；CCA = 「有能力設計生產級 Claude 應用」。
