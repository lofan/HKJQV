➕ 如何新增連結 How to add new links

所有連結都存放喺同目錄嘅 links.json，頁面載入時會用 fetch() 讀入。想加新連結，淨係要喺 links 陣列度加一個 object，畫面會自動生成卡片、自動歸入分類、自動可以搜尋 — 唔使再改呢個 HTML。

{ "name": "新連結名稱", "url": "https://lofan.github.io/HKJQV/xxx.html", "cat": "財經投資" }

如果 cat 打一個未出現過嘅新分類名，個新分類版塊會自動出現喺頁面度。想令個分類固定排喺前面，可以喺 links.json 嘅 catOrder 陣列度加返個名。

注意：JSON 唔准有尾隨逗號（trailing comma）同註解，格式出錯會顯示錯誤訊息。另外直接雙擊開本機 file:// 檔案時瀏覽器會擋住 fetch()，要用 GitHub Pages 或者本機伺服器（例如 python -m http.server）先睇到。
