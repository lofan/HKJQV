Wikipedia & Multi-Engine Search Tool
A lightweight, single-page web application designed for rapid information discovery and research. This tool integrates Wikipedia searching across multiple languages and provides quick-access shortcuts to popular search engines and platforms.
Features
Multi-Language Wikipedia Support: Easily switch between 8 different languages (ZH, EN, JP, KR, FR, DE, ES, IT).
Inspiration Mode: Click the "靈感" button to generate a random topic based on your selected language and start learning.
External Search Shortcuts: One-click shortcuts to popular platforms including Amazon, SearXNG, DuckDuckGo, YouTube, Britannica, and X.
Search History: Automatically saves your recent queries to your browser's local storage for quick access.
Theme Toggle: Built-in support for Dark and Light modes.
Market/Trend Insights: Direct links to daily trending searches for HK, US, and JP.
How to Use
Open: Simply open the index.html file in any modern web browser.
Search: Enter your query into the search bar and press Enter.
Explore: Use the language navigation menu to toggle the Wikipedia source language.
Randomize: Use the "靈感" button for a suggested topic, or "隨機" to visit a random Wikipedia page.
Technical Stack
Frontend: Vanilla JavaScript, HTML5, and CSS.
Styling: Bootstrap 5 with custom CSS variables for themes.
Icons: FontAwesome.
API: Uses the MediaWiki API for real-time search results.
Persistence: Uses localStorage to manage your search history locally.
