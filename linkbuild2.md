LinkForge HTML BuilderLinkForge is an elegant, responsive, single-page web utility designed to parse messy text, sanitize nested HTML/spaces, organize lists of links interactively, and export them into beautiful HTML, Markdown, or JSON.🚀 Features1. Smart Input Cleansing & SanitizationOften, copying lists of links from rich-text editors (like Microsoft Word, Google Docs, or other web pages) introduces bloated HTML markup. LinkForge resolves this by:Automatically identifying and stripping nesting <div> and </div> tags while retaining inner link components.Converting HTML non-breaking spaces (&nbsp;) and Unicode non-breaking character sequences (\xa0) into clean, single-spaced characters.Sanitizing raw text and extracting pure destination URLs seamlessly.2. Dual-Extraction EngineThe built-in parser runs two parallel detection passes on your input:HTML Anchors: It extracts already existing HTML links (e.g., <a href="...">Link Text</a>) and populates both the URL and the user-facing text.Raw URLs: It sweeps the remaining text for naked protocols (e.g., https:// or http://) to register any links that were entered without HTML wrappers.3. Dynamic Fallback GenerationIf a link has no anchor text, LinkForge offers custom fallback generation policies:Domain Name: Automatically extracts the hostname and capitalizes the name (e.g., https://www.google.com becomes Google).Raw Link URL: Keeps the full destination URL as the label text.Numbered List: Creates incremental identifiers (e.g., Link #1, Link #2).Text Case Styling: Offers global text transformation rules to enforce uppercase, lowercase, or keep the original capitalization formats.4. Interactive Link ManagerDirectly reorder, refine, or prune your parsed results in real-time:Manual Insertion: Quickly append individual items manually.Sorting Control: Shift links up or down to curate their sequence.Live Overrides: Modify individual anchor text labels and destinations instantly.Deletion: Tap the trash icon to discard unwanted items instantly.5. Advanced Layout & Export ConfigurationsTransform your clean links into several ready-to-publish frameworks:Output Formats: - Unordered HTML Lists (<ul> and <li>)Ordered HTML Lists (<ol> and <li>)Stacked Divs (<div class="link-item">)Inline Links (spaced with elegant bullet separators •)Raw Anchors (new line separated)Target Configurations: Inject target="_blank", target="_self", or omit targets completely.Rel Configurations: Apply search engine parameters like rel="noopener noreferrer", rel="nofollow", or omit them.Custom CSS: Inject specific Tailwind CSS or global class names dynamically into the generated code block.6. Interactive Multi-Tab WorkspaceGenerated HTML: View clean, syntax-highlighted HTML block elements.Visual Preview: See exactly how the browser renders the styled links inside a sandbox.Markdown List: Grab clean markdown formats (e.g., -[Label](URL)) to paste into GitHub, Notion, or Slack.Raw JSON: Copy data structures for programmatic or database imports.🛠️ Technical StackFramework/Style: Tailwind CSS (configured with dark-mode utility class selection)Icons: FontAwesome v6.4.0Fonts: Inter & Fira Code (via Google Fonts)Language: Vanilla ECMAScript 6 JavaScript (no heavy backend frameworks, ensuring ultra-fast loading times)📖 How to UseInput: Paste your dirty text block (with &nbsp;, <div> tags, or plain links) inside the text area in Step 1. Alternatively, click "Try Sample" to see a demo.Review: Watch the Step 2: Link Manager populate instantly with individual link cards. Clean up spelling, adjust links, or drag/move their ranks.Configure: Use Step 3 to choose your layout format (e.g., <ul>), open targets, rel safeguards, and optional class values.Copy & Export: Swap between the HTML, Preview, Markdown, and JSON tabs. Click "Copy" to send the processed code directly to your clipboard.
