🚀 快速上手

呢個工具係一個離線可用嘅網頁應用（Single File Web App）。你唔需要安裝任何程式，亦無需註冊任何帳號，只需 3 秒就可以開始：

1

下載並保存網頁

將 youtube_learning_channels.html 檔案下載並儲存到你嘅電腦或手機。

2

雙擊打開（Double Click）

直接喺你常用嘅瀏覽器（好似 Chrome, Safari, Edge, Firefox 等）打開呢個檔案。

3

即時自學

點擊任何頻道名稱，網頁就會幫你在新分頁打開 YouTube，方便一邊睇網頁一邊睇片！

✅ 進度追蹤與搜尋

☑️ 點擊剔選（Check/Uncheck）

當你睇完某個頻道或者已經訂閱咗佢，可以點擊頻道名稱左邊嘅 Checkbox。

  • ✔️ 剔選後字體會變淡並加上刪除線。
  • ✔️ 頂部嘅「解鎖進度」計數器會即時自動累加。

🔍 實時精準篩選

頻道太多好難搵？頂部嘅搜尋欄支援實時模糊搜尋。

  • 🔍 輸入「math」：即時列出所有數學類別同相關頻道。
  • 🔍 輸入頻道名字（e.g. 「Vsauce」）：其他無關卡片會即時收起。

✏️ 自由編輯頻道 (自定義管理)

系統賦予你完全自由！如果你有更鍾意嘅頻道，或者原裝某個頻道唔啱睇，隨時可以做出修改：

➕

新增頻道

喺任意分類卡片下方點擊「新增頻道」，填寫頻道名稱同連結，即可一秒加入列表。

✏️

修改資料

滑鼠移到頻道行上，右邊會出現紫色「鉛筆」按鈕。點擊即可彈出視窗修改名或者連結。

🗑️

刪除頻道

點擊紅色「垃圾桶」按鈕，系統會以精美自製 Modal 彈出二次確認，防止手誤刪除。

💾 數據備份與還原

為免瀏覽器快取被清空、換新電腦或者想同朋友分享你嘅專屬自學地圖，我哋準備咗備份功能：

📤 匯出數據 (Export Backup)

點擊網頁右上方嘅「匯出數據」按鈕。系統會將所有頻道配置及剔選進度打包成一個 JSON 備份檔案，並自動下載保存。

產生 .json 檔

📥 匯入數據 (Import Restore)

點擊「匯入數據」，選擇你之前備份嘅 JSON 檔案。系統會即時分析檔案格式，一秒完美復原你嘅所有記錄。

還原 / 轉移

🔒 數據私隱安全說明

💡 運作機制 (Local Storage)：
網頁使用咗 HTML5 標準中嘅 LocalStorage 技術。你進行嘅所有更改（新增頻道、打勾進度等）只會儲存在你本機瀏覽器嘅沙盒空間。

🛡️ 無網無伺服器，安全無憂：
呢個網頁完全無後端伺服器（Serverless），亦無任何第三方統計或廣告追蹤程式碼。你嘅自學數據 100% 掌握喺你自己手，無人可以窺探。

❓ 常見問題 (FAQ)

Q1: 點解我清完瀏覽器垃圾，進度唔見晒？

因為本網頁將數據儲存在 LocalStorage。如果你使用清潔軟體、或者點擊「清除網站所有資料/Cookies」，瀏覽器會強制清空此快取。建議每次進行大幅修改後，順手點點「匯出數據」下載備份，以防萬一。

Q2: 我想喺手機睇同埋喺電腦睇，點樣同步？

由於無雲端伺服器，你只需喺電腦版點擊「匯出數據」，透過 AirDrop、微信、WhatsApp 或者 Email 將備份 JSON 檔案同 HTML 主檔案傳去手機，再喺手機打開點擊「匯入數據」，就可以完美接續學習！

Q3: 我改到好亂，想全部重頭嚟過，點搞？

好簡單！點擊網頁右上角嘅「恢復預設」紅色按鈕，喺彈出嘅對話框點擊確定，系統就會將所有 LocalStorage 數據洗乾淨，並重新載入最原始、精挑細選嘅 100 個黃金學習頻道！
